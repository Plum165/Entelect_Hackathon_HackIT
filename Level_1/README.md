# The Ranger's Rescue Route — Level 1

## Overview

This project contains a Python solution for **Level 1** of
"The Ranger's Rescue Route" shortest-path optimisation challenge.

The objective is to find the shortest route from node `A` to node `B`
through a weighted, undirected graph.

Level 1 contains:

- 6 nodes
- Weighted edges
- No risk values
- Start node: `A`
- End node: `B`
- No required intermediate stops

The edge weight represents the travel time.

---

## Files

The project should contain the following files:

```text
level1/
├── 1.txt
├── level_1.py
├── level1_submission.txt
├── level_1.ipynb
└── README.md
```
1.txt

The input graph supplied by the challenge.

solution.py

The Python program that loads the graph, runs Dijkstra's algorithm,
finds the shortest route, and creates the submission file.

level1_submission.txt

The JSON output generated by the program.

README.md

This file, explaining the solution and how to run it.

# Requirements

Python 3.8 or newer is recommended.

The solution only uses Python's standard library.

No external packages need to be installed.

The program uses:

json for reading and writing JSON.
heapq for the priority queue used by Dijkstra's algorithm.

# Running the Program

Open a terminal in the project directory.

Run:

```bash
python level_1.py
```

On some systems, you may need:

```bash
python3 level_1.py
```
The program expects 1.txt to be in the same directory as
`level_1.py`.
